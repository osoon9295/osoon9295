## 안녕하세요, 이보영입니다 👋

**사용자 흐름을 분석하고, 리스크를 기반으로 검증 범위를 설계하는 QA 엔지니어입니다.**

프론트엔드 개발 경험을 바탕으로 UI 상태, 인증 흐름, 브라우저 동작에 대한 이해를 갖추고 있습니다.

현재는 **테스트 설계 기법과 리스크 기반 테스트(Risk-Based Testing)** 를 활용하여 테스트 케이스를 작성하고, Playwright를 통해 핵심 사용자 시나리오를 자동화하는 데 집중하고 있습니다.

단순히 테스트를 실행하는 것을 넘어, **무엇을 검증해야 하는지, 왜 중요한지, 어떤 테스트를 자동화해야 하는지** 고민합니다.
